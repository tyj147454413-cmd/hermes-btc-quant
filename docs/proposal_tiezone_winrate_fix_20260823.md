## 一、三个数学事实（全部机算可复核）

### 事实 1：在方向层面换判法——此路不通

投票器定义的"危险场次"（顺引擎票数 ≤1）共 62 场，现状引擎命中 56.5%。
把危险场的方向交给任何其他裁判，8 种替代判法**全军覆没**：

| 替代判法 | 危险场胜率 | 全区合成胜率 | vs 现状 68.5% |
|---|---|---|---|
| 四因子多数 | 43.5% | 64.1% | -4.4pp |
| PM 方向 | 53.2% | 67.4% | -1.1pp |
| Taker 即时 | 53.2% | 67.4% | -1.1pp |
| recent_dir 15m（最强） | 54.8% | 68.0% | -0.5pp |
| 价格位置 sign(dev) | 54.8% | 68.0% | -0.5pp |
| 上一小时方向 | 45.2% | 64.6% | -3.9pp |

**结论：没有任何因子/组合能在危险场上赢过现行引擎。** 引擎错了的时候，别的指标错得更狠。
→ 所谓"完美修复"不存在于翻向；只能从【跳过差场次】和【拿到更好的信息再决策】两个方向要胜率。

### 事实 2：跳过差场次能抬实现胜率，但要付钱（或几乎免费）

固定 $10 口径模拟（181 场，按各场真实买价）：

| 方案 | 实现胜率 | 模拟 P&L | 代价 |
|---|---|---|---|
| S0 现状 | 68.5%（124/181） | +609.96U | — |
| S1 双弱区 SKIP（≤1票 且 PM<0.55，约30场） | **72.2%**（109/151） | +603.44U | 仅 -6.52U ≈ 免费 |
| S2 ≤1票全 SKIP（62场） | **74.8%**（89/119） | +560.50U | -49.46U |

- S2 提升最猛但最贵：被跳过的危险场整体仍是赚钱的（低价买入时 56% 胜率也有正 EV）；
- S1 是性价比之王：胜率 +3.7pp，利润只让 1%。**但它违反 round13 全量交易原则，必须用户批准修例才能做。**

### 事实 3：最便宜的胜率提升是"晚几分钟再决定"——+10 个百分点

贴线区历史上有 ≥2 份快照的对子 131 组（首末中位间隔 ≈13 分钟）：

- 早快照决策命中 **59.5%** → 晚快照决策命中 **69.5%**（Wilson 区间不重叠）；
- 其中方向发生改变的 32 组：改后判对 68.8%，前后半切稳定（62% / 75%）；
- 机制：贴线区价格贴着锚定线抖动，早采集时信息未分化；多等十几分钟，四票信息与方向一起变清晰。

这是**唯一不需要 SKIP、不需要改注额、纯靠流程就能拿到的两位数提升**，
且与待回测清单最高优先级条目「贴线抖动场 refresh 敏感度 0.10%→0.05% + 写后复核」完全同源。

## 二、完美修复方案（三层结构）

```
第一层 影子记录（零风险，立即）
  └─ 信号 JSON 增加 tie_votes 字段（0-4票+各成员读数），复盘同步归档
第二层 强制复核（提胜率主力）
  └─ 贴线区（|dev|<0.15%）信号发出前强制二次采集重算，方向以复核为准
     （对应现有 last-check/refresh 铁律的贴线特化：阈值收紧 + 不跳过复核）
第三层 双弱区 SKIP（可选，需修 round13）
  └─ ≤1票 且 PM对我方<0.55 → 本小时 SKIP（唯一新增 SKIP 场景）
```

**预期叠加效果（保守估计，取各层不重复部分）：**
- 第二层单独：贴线区决策质量 59.5%→69.5% 口径的历史映射 ≈ **+8~10pp**；
- 第三层叠加：实现胜率再 **+3~4pp**（代价 ~6.5U/半年样本期）；
- 合计：贴线区实现胜率有望从 68.5% 推向 **78%~80%** 区间（前瞻验证前不作承诺）。
